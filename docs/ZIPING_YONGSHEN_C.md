# 喜用引擎 C（《滴天髓》眾寡優先）

> ruleId: `yongshen-ditian-zhonggua-v1`  
> 性質：研究用可重現規則；不保證對攪珠有預測力。

## 主腦

1. **眾寡論**（《滴天髓》）：先計全局五行／兩黨多寡與氣勢  
2. **通關**：兩黨交戰時優先  
3. **調候**：寒暖燥濕；冬無火／夏無水可升主用  
4. **從勢／從格**：日主無根且一邊極眾則順眾  
5. **正格用神表**（《子平真詮》輔助）：僅格清未破時使用  
6. **扶抑**：其餘情況按眾寡做病藥

## 優先序

```
① 合沖合化（改力、改黨）
② 五行／兩黨眾寡計分
③ 從勢？ → 順眾用神（調候不逆從）
④ 交戰？ → 通關為主
⑤ 清正格未破？ → 格局用神（輔助）
⑥ 否則按眾寡扶抑
⑦ 調候：次喜；冬無火／夏無水 → 並列主用
```

## 眾寡計分（v1）

| 來源 | 權重 |
|------|------|
| 天干 | 1.0 |
| 月支本氣 | 2.0 |
| 其餘地支本氣 | 1.0 |
| 藏干中氣／餘氣 | 0.5 |

再乘合沖係數：相沖 ×0.5；合絆 ×0.7；合化成功則改計化後五行。

**日主黨** = 日主 + 印 + 比劫  
**他黨** = 食傷 + 財 + 官殺

比例 ≥ 2:1 視為眾寡分明。

## 通關（簡表）

兩行相剋對峙時，取「生兩者之間」的五行作通關（例如木金交戰取水等——實作表見代碼）。

## 調候

| 月支 | 調候喜 |
|------|--------|
| 亥子丑 | 火 |
| 巳午未 | 水 |
| 其餘 | 弱次喜或不升主 |

缺暖潤（冬無丙丁、夏無壬癸）→ 調候升主用之一。

## 與取號

本引擎輸出 `yong_shen` / `xi_shen` / `ji_shen`。  
攪珠 15 碼預設仍以干支映射為主；喜用池僅 A/B。
