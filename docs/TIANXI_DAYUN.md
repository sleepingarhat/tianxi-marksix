# 天喜大運流年引擎

> `engineId`: **`tianxi-dayun-v2`**  
> 入口：`src/tianxi_dayun.py` · 總盤：`src/tianxi_engine.py`

男女命、起運時刻、當下大運、流年——四樣一次出齊。判斷當運用交運公曆，唔用整歲估。

## 規則

1. **年干陰陽 × 性別**  
   陽男陰女順行，陰男陽女逆行。年干取立春換年。
2. **排柱**  
   以月柱為起點，順推或逆推，每步十年。`index=0` 為童限（未交運，柱用月柱）。
3. **起運只用十二節**  
   立春、驚蟄、清明、立夏、芒種、小暑、立秋、白露、寒露、立冬、大雪、小寒。  
   順行數至出生後下一節；逆行數至出生前上一節。交節時刻用天文儒略日。
4. **分鐘折算**  
   4320 分 = 1 年，360 分 = 1 月，12 分 = 1 日，餘分 × 2 = 時。  
   交運公曆 = 出生時刻 + 年／月／日／時。
5. **當運／流年**  
   錨點（例如攪珠日 21:30 HKT）落入哪段 `start_solar ≤ t < end_solar` 即該步大運。  
   流年柱為該公曆年立春年柱。

## 節氣對照

```bash
python src/tianxi_jieqi_check.py 1988
python src/tianxi_jieqi_check.py 2026
```

樣本：1988-02-08 04:00 順行下一節 = **驚蟄 1988-03-05 16:46:32**；逆行上一節 = **立春 1988-02-04 22:42:49**（北京／香港時間）。

sxtwl 自身掃描差距 ≤ 2 秒；與 tyme4py / lunar-python 約 0–20 秒，起運折算到日即可忽略。

## 指令

```bash
python src/tianxi_dayun.py --birth 1988-02-08T04:00 --sex male --at 2026-08-22T21:30
python src/tianxi_engine.py --birth 1988-02-08T04:00 --sex 男 --at 2026-08-22T21:30
python src/dayun.py 1988 2 8 4 male
```

性別：`male` / `female` / `男` / `女`。
