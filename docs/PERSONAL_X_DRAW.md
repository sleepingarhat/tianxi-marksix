## A. 個人八字 × 攪珠日八字

### 輸入

- `personal`: 出生公曆 Y-M-D + 時辰（0–23，對應時柱）
- `draw_date`: 攪珠公曆日（時固定 21:30）

### 起盤

- 兩邊都用同一套四柱（sxtwl，立春換年、節令換月）
- 個人：用戶出生時；攪珠：21:30

### 取數（v1 簡規）

只做**干支映射打分**，**不用喜用池**：

| 來源 | 權重 |
|------|------|
| 攪珠日：時柱映射 | 4.0 |
| 攪珠日：日柱映射 | 3.0 |
| 攪珠日：月柱映射 | 2.0 |
| 攪珠日：年柱映射 | 1.5 |
| 個人：日柱映射 | 3.0 |
| 個人：時柱映射 | 2.5 |
| 個人：月柱映射 | 2.0 |
| 個人：年柱映射 | 1.5 |
| 兩盤日主五行河圖尾數 | 各 1.0 |

映射：干序、支序、干支序和／積 mod 展開到 1–49 候選累加權重。  
最後 `pick15()`。

輸出 JSON 含：`personal_pillars`、`draw_pillars`、`numbers[15]`、`ruleVersion`。
