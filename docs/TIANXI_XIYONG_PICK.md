# 天喜喜用取號

> `ruleVersion`: **`tianxi-xiyong-pick-v1`**  
> 入口：`src/tianxi_xiyong_pick.py` · 前端：`TXMarkSixEngine.xiyongPick`

格局喜用表同大運已鎖定，本刀把 **用／喜／忌／仇**、**當運**、**流年**、**攪珠日四柱** 疊入 15 碼權重。  
獨測（無個人盤）同奇門合盤 **不改**。

## 輸入

- 個人出生公曆 + 時辰
- 男命／女命（起大運）
- 攪珠日（時固定 21:30 HKT）

## 分層

| 層 | 來源 | 作用 |
|----|------|------|
| A | `personal-x-draw-v1` | 兩盤干支映射＋日主河圖，骨架保留 |
| B | 本命格局喜用 | 用喜忌仇 → 河圖尾數加減 |
| C | 當運干支 | 干／支五行對照喜用表加減 |
| D | 流年干支 | 同上，權重較細 |
| E | 攪珠日四柱 | 時＞日＞月＞年，對照本命喜用 |
| F | 交互 | 當運×流年同氣／沖剋微調 |

## 河圖尾數

水 1·6 · 火 2·7 · 木 3·8 · 金 4·9 · 土 0·5

## 鎖定權重

### B 本命五行

| 角色 | 權重 |
|------|------|
| 用 | +2.5 |
| 喜 | +1.2 |
| 忌 | −1.2 |
| 仇 | −2.0 |
| 調候急要（且已在用／喜） | 該行再 +0.8 |

### C 當運

| 角色 | 天干 | 地支 |
|------|------|------|
| 用 | +2.0 | +1.2 |
| 喜 | +1.0 | +0.6 |
| 忌 | −1.0 | −0.6 |
| 仇 | −1.8 | −1.0 |

童限用月柱當運。

### D 流年

| 角色 | 天干 | 地支 |
|------|------|------|
| 用 | +1.4 | +0.8 |
| 喜 | +0.7 | +0.4 |
| 忌 | −0.7 | −0.4 |
| 仇 | −1.2 | −0.7 |

### E 攪珠日對本命喜用

| 柱 | 用干／支 | 喜干／支 | 忌干／支 | 仇干／支 |
|----|----------|----------|----------|----------|
| 時 | +1.6 / +1.0 | +0.8 / +0.5 | −0.8 / −0.5 | −1.4 / −0.9 |
| 日 | +1.2 / +0.8 | +0.6 / +0.4 | −0.6 / −0.4 | −1.1 / −0.7 |
| 月 | +0.6 / +0.4 | +0.3 / +0.2 | −0.3 / −0.2 | −0.6 / −0.4 |
| 年 | +0.4 / +0.3 | +0.2 / +0.15 | −0.2 / −0.15 | −0.4 / −0.25 |

### F 交互（只加一次，作用於該五行河圖）

| 條件 | 加減 |
|------|------|
| 當運天干用 ∧ 流年天干用 | 用 +0.8 |
| 當運天干用 ∧ 流年天干忌 | 用 −0.5 |
| 當運天干忌 ∧ 流年天干用 | 用 +0.3 |
| 當運天干仇 ∧ 流年天干仇 | 仇 −0.8 |

角色優先：用 > 喜 > 忌 > 仇；同一五行只屬一角色。

## 取 15

沿用 `pick15()`：五段目標各 3，不足由剩餘高分補。
