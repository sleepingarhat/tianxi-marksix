# 天喜六合彩研究（tianxi-marksix）

研究簿模組：**只用兩術**——**四柱八字**、**奇門遁甲（地盤取數）**。  
目標：取代現有頁面 [`tianxi-site.pages.dev/marksix`](https://tianxi-site.pages.dev/marksix/)。

> 性質：可重現研究工具，非投注建議。

---

## 總則（兩術共用）

| 項目 | 定案 |
|------|------|
| 時間錨點 | 該期攪珠日 **21:30:00 Asia/Hong_Kong** |
| 每術產出 | **15 個不重複號碼**（1–49） |
| 計分 | 正碼每中 **+1**；特別號若在 15 碼內 **+0.5**；上限 6.5 |
| 分段 | 五段 `1–9 / 10–19 / 20–29 / 30–39 / 40–49`，目標每段 **3** 碼 |
| 不足規則 | 某段不足 3 → 能取多少取多少；欠額由**剩餘高分最多**的另一段改取 4（或再補） |
| 日界 | 公曆攪珠日；農曆／節氣只服務排盤內部 |

**已棄用（本倉庫不實作）：** 梅花、太乙、六爻納甲、奇門天盤入取數。

## 一、四柱八字

### 1.1 起盤

1. 時刻：攪珠日 **21:30 HKT**
2. 年柱：立春換年
3. 月柱：節令換月
4. 日柱、時柱：標準萬年曆（亥時 = 21:00–23:00）
5. 輸出：四柱干支、日主、月令、簡表旺衰、喜用／忌（簡表）

**喜用簡表（第一版）：**

- 日主得令（旺／相）：喜用 = 剋身、洩身；忌 = 日主同類
- 否則：喜用 = 比劫、印；忌 = 剋身、洩身

### 1.2 取數

| 來源 | 權重 |
|------|------|
| 喜用五行河圖尾數池 | 5.0 |
| 忌五行河圖池 | 0.5 |
| 年柱干支映射 | **1.5** |
| 月柱干支映射 | **2.0** |
| **日柱**干支映射 | **3.0**（正式鎖定） |
| **時柱**干支映射 | **4.0**（正式鎖定） |

干支映射：天干序、地支序、和／積等展開到 1–49 多組候選後打分。  
最後用共用 `pick15()`（五段×3）。

**河圖尾數：** 水 1,6｜火 2,7｜木 3,8｜金 4,9｜土 0,5。

## 二、奇門遁甲（時家 · 拆補 · **僅地盤取數**）

### 2.1 起盤

1. 用 21:30 定日時干支
2. **拆補定局**
   - 節氣 → 查陽／陰遁及上中下元局數表
   - 符頭：往前最近甲／己日；offset 0–4 上元、5–9 中元、10–14 下元
   - 得：陰／陽遁 + 局數 1–9
3. **地盤**：三奇六儀「戊己庚辛壬癸丁丙乙」
   - 陽遁：戊起於局數宮，順布九宮
   - 陰遁：戊起於局數宮，逆布九宮
4. 時旬首 → 遁甲寄六儀；**值符原宮** = 該六儀地盤宮；**值符宮** = 時干（甲則寄六儀）地盤落宮

> 天盤／人盤／八神可計算作展示，**正式取數不採用**（40 期對比顯示加入後平均字數下降）。

### 2.2 取數（地盤版 · 正式鎖定）

| 來源 | 權重 |
|------|------|
| 各宮地盤干 + 宮數映射 | 值符宮 3.5；值符原宮 3.0；其餘 2.0 |
| 三奇（乙丙丁）所在宮 | 3.0 |
| 遁性輔助（陽→金池／陰→水池） | 1.5 |

再 `pick15()`。
